# Trash Change Labeler

面向遥感和无人机双时相垃圾变化检测的数据标注工具。所有图像处理均在浏览器本地完成，不上传数据。

## 启动

```powershell
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。生产构建使用：

```powershell
npm run build
npm run preview
```

## 输入和标准裁切

先点击“新建样本”创建并选中一个空样本，再使用顶部两个按钮分别上传 T1、T2。每次上传只写入当前选中样本，与上传文件名无关；重新上传会覆盖当前样本对应的时相。可以在左侧删除当前样本，其他样本不受影响。

工具提供固定正方形裁切框，可选择 `224`、`256`、`384`、`512`、`768` 或 `1024`。默认输出 `512×512`，适合当前 RemoteCLIP 双时相训练方案。拖动裁切框时，T1、T2 和掩膜始终使用同一坐标；图像采用平滑插值，掩膜采用最近邻插值。

## 训练结果目录

点击“选择结果目录”指定输出根目录，再选择 `train`、`val` 或 `test`。点击“保存训练裁片”后生成：

```text
所选结果目录/
├── train/
│   ├── t1/scene_001_x0000_y0000_s512.png
│   ├── t2/scene_001_x0000_y0000_s512.png
│   └── masks/scene_001_x0000_y0000_s512_change_mask.png
├── val/
│   ├── t1/
│   ├── t2/
│   └── masks/
└── test/
    ├── t1/
    ├── t2/
    └── masks/
```

三个输出文件尺寸完全相同，T1/T2 为 RGB PNG，掩膜为仅含黑白像素的二值 PNG。浏览器安全机制不会向网页公开完整磁盘绝对路径，因此界面会显示所选目录名和内部相对路径；文件实际写入用户在系统目录选择器中指定的位置。Chrome/Edge 支持直接写目录，不支持目录写入的浏览器会退化为三个 PNG 下载。

## 标注流程

1. 点击“新建样本”并输入样本名称。
2. 保持该样本选中，分别点击“上传 T1”和“上传 T2”。
3. 选择裁切输出尺寸和 `train/val/test` 数据集。
4. 使用裁切工具 `C` 拖动固定裁切框。
5. 使用 T1、T2 或叠加视图确认变化位置，并用画笔、橡皮或多边形标注。
6. 选择结果目录，点击“保存训练裁片”。

常用快捷键：`B` 画笔、`E` 橡皮、`P` 多边形、`H` 平移、`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+S` 导出、`[`/`]` 调整笔刷。

```powershell

```
